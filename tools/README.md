# tools — проверки и обслуживание комплекта

Требуется Node.js и два пакета: `npm install jsdom xlsx` (ставятся в
`node_modules` рядом с репозиторием либо задаются переменной
`PPO_NODE_MODULES`).

## Полный прогон

    sh tools/run-all.sh

## По отдельности

| Команда | Что проверяет |
|---|---|
| `node tools/check-syntax.js` | синтаксис всех `.js` и встроенных скриптов `.html` |
| `node tools/test-core.js` | справочники, расчёты пролётов и хода линии, книга значениями |
| `node tools/test-template.js` | заполнение `ID_shablon.xlsx` и обратное чтение |
| `node tools/test-pages.js` | страницы в браузерном окружении: поля, сохранение, быстродействие карты |

`tools/harness.js` — общая обвязка: поднимает страницу в jsdom, подставляет
локальные скрипты, заменяет Leaflet заглушкой со счётчиком обращений к слоям
(на нём держится проверка «перекраска не пересоздаёт все метки»).

## Обновление шаблона исходных данных

    node tools/dump-refs.js          # справочники ядра → tools/refs.json
    python3 tools/build-template.py  # перестроить листы Спр_* в ID_shablon.xlsx
    node tools/test-template.js      # сквозная проверка

Книга правится по внутренней разметке, а не пересохранением: в ней двадцать с
лишним проверок ввода (включая связанный список марок опор через `INDIRECT`),
семь листов с примечаниями и своё оформление — пересохранение любой
библиотекой всё это теряет.
