# Выкладка на GitHub Pages

Все файлы кладутся в **корень** ветки — не в подпапку. Пути в коде плоские
и относительные (`ppo-core.js`, `ID_shablon.xlsx`), из подпапки инструмент не заработает.

## Порядок

1. Распакуйте архив и загрузите содержимое в корень репозитория
   (Add file → Upload files → перетащить всё разом).
2. Settings → Pages → Source: Deploy from a branch → ветка `main`, папка `/ (root)`.
3. Подождите 1–2 минуты, откройте выданный адрес.

Точка входа — `index.html` (генератор отчёта). Главная страница со списком
инструментов — `portal.html`.

## Файл `.nojekyll`

Пустой файл в корне. Отключает обработку Jekyll на стороне GitHub Pages.
Скрытые файлы через веб-интерфейс GitHub загружаются не всегда — если `.nojekyll`
не появился, создайте вручную: Add file → Create new file → имя `.nojekyll` → Commit.

## Проверка после выкладки

| Шаг | Что должно произойти |
|---|---|
| `portal.html` | синяя полоса разделов, плитки инструментов |
| «Осмотр» → вкладки | восемь: Объект, Линии, Опоры, Измерения, Дефекты, Приборы, Кабели, Проверка |
| «Осмотр» → Опоры → фото в карточке | клик по миниатюре открывает просмотр с зумом и листанием |
| «Карта» → правка метки → Сохранить | появляется сообщение о переносе в осмотр |
| «Карта» → «Из осмотра» | опоры с координатами становятся метками |
| «Осмотр» → Проверка → «Скачать шаблон Excel» | `ID_shablon.xlsx` открывается, 15 листов |
| `index.html` → загрузить шаблон | собирается отчёт, «Лист внутреннего контроля», 43 проверки |

## Синхронизация «Карта» ↔ «Осмотр → Опоры»

Обе страницы правят один и тот же набор опор.

* Сопоставление — по паре «линия + номер опоры»; если номер сменился, опора
  находится по координатам (допуск ~1,5 м). Дубли не создаются.
* С карты приходят координаты, категория дефекта, номер и линия.
  Марка, класс, пролёт, местность и прочие поля, заполненные в «Осмотре»
  вручную, при синхронизации **не затираются**.
* Метки без номера опоры не переносятся — сопоставлять их не с чем.
* Кнопка «⇄ Синхронизация» переключает автоматический режим и ручной.
  В ручном правки уходят в осмотр только по кнопке «→ В осмотр».
* Фотографии, добавленные на карте, попадают в общее хранилище и привязываются
  к опоре; повторный перенос дублей не создаёт.

## Внешние библиотеки

Страницы подключают CDN: `cdnjs.cloudflare.com` (XLSX, JSZip, PDF.js, proj4),
`unpkg.com` (Leaflet), `cdn.jsdelivr.net` (exifr). Нужен доступ к ним из сети
предприятия, иначе не заработают импорт KMZ, карта и разбор PDF.
