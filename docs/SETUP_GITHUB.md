# Как дать Claude доступ к этому репозиторию

Инструкция для Анатолия. Ничего устанавливать не нужно, всё делается в браузере.
Пункты 1–3 выполняются один раз, дальше работа идёт в задачах репозитория.

Два способа получить одно и то же. Начните с первого — он проще.

---

## Способ 1. Писать «@claude» прямо в задачах репозитория

Так выглядит работа после настройки: вы создаёте задачу, описываете, что нужно
сделать, и Claude сам вносит правки и открывает запрос на слияние. Вы смотрите,
что изменилось, и сливаете.

### 1. Поставить приложение Claude на репозиторий

Откройте https://github.com/apps/claude → **Install** → выберите этот
репозиторий (`VOLS_ARM_V25`). Понадобятся права владельца репозитория.

Приложение попросит доступ на чтение и запись к файлам, задачам и запросам на
слияние — без этого оно не сможет вносить правки.

### 2. Добавить секрет

Секрет — это то, чем рабочий процесс подтверждает, что обращается к Claude от
вашего имени. Выберите один вариант.

**Вариант А, по подписке Claude** (Pro, Max, Team, Enterprise). В терминале на
компьютере с установленным Claude Code выполните `claude setup-token` и
скопируйте полученный токен. Если терминалом не пользуетесь, переходите к
варианту Б.

**Вариант Б, по ключу Claude API.** Ключ создаётся в консоли
https://platform.claude.com. Оплата в этом случае идёт по расходу токенов, а не
по подписке.

Дальше в репозитории: **Settings → Secrets and variables → Actions → New
repository secret**.

| Вариант | Имя секрета |
|---|---|
| А, подписка | `CLAUDE_CODE_OAUTH_TOKEN` |
| Б, ключ API | `ANTHROPIC_API_KEY` |

В значение вставьте токен либо ключ. **Никогда не вставляйте их в переписку и
в файлы репозитория** — только в секреты.

Если выбрали вариант Б, поправьте два файла в `.github/workflows/`: в
`claude.yml` и `claude-review.yml` замените строку

```yaml
claude_code_oauth_token: ${{ secrets.CLAUDE_CODE_OAUTH_TOKEN }}
```

на

```yaml
anthropic_api_key: ${{ secrets.ANTHROPIC_API_KEY }}
```

### 3. Проверить

Создайте задачу: **Issues → New issue**, заголовок «Проверка связи», в тексте:

```
@claude прочитай CLAUDE.md и напиши, что ты понял про правила этого проекта.
Ничего не меняй.
```

Ответ приходит в ту же задачу, обычно за минуту. Если тихо — см. «Если не
работает» ниже.

### Как ставить задачи

Пишите так, как писали в переписке: своими словами, с описанием того, что не
работает. Claude прочитает `CLAUDE.md`, найдёт нужное место в коде, внесёт
правку, прогонит проверки и откроет запрос на слияние.

```
@claude В разделе «Карта» при открытии опоры подписи фотографий
показывают только имя файла. Нужно добавить номер опоры и линию,
как в разделе «Осмотр».
```

Полезные замечания:

* **Одна задача — одна тема.** Пять несвязанных правок в одной задаче Claude
  сделает хуже, чем пять задач по одной.
* **Правку смотрите перед слиянием.** В запросе на слияние вкладка **Files
  changed** показывает, что именно изменилось. Рядом автоматически появляется
  разбор правки от Claude.
* **Проверки запускаются сами** на каждый запрос (`Проверки` в списке).
  Зелёная галочка — проверки прошли, красный крест — сливать нельзя.
* **Продолжить разговор** можно комментарием «@claude …» в самом запросе на
  слияние: Claude допишет правку в ту же ветку.

## Способ 2. Claude Code в браузере

Открываете https://claude.ai/code, подключаете учётную запись GitHub, выбираете
репозиторий и ставите задачу текстом. Claude клонирует репозиторий в отдельную
машину, работает и присылает ветку с правками на проверку. Терминал и установка
не нужны.

Доступно на подписках Pro, Max и Team, а также Enterprise с соответствующими
местами; на момент написания — в режиме предварительного доступа. Сессии не
пропадают при закрытии браузера, за ними можно следить из мобильного приложения.

Этот способ удобнее, когда задача не оформлена: можно поговорить, посмотреть
код, попробовать варианты. Способ 1 удобнее, когда задача понятна и нужен
результат в виде запроса на слияние.

Оба способа читают `CLAUDE.md` и живут в одном репозитории, так что можно
пользоваться обоими.

---

## Чего Claude в обычной переписке сделать не может

В этом окне переписки (claude.ai) прямого доступа к репозиторию нет: файлы
репозитория я могу только читать как открытые страницы, а записывать в него —
нет. Именно поэтому до сих пор комплект передавался архивом, который вы
загружали руками. После настройки по этой инструкции ручная загрузка больше не
нужна.

## Если не работает

| Что видно | Что проверить |
|---|---|
| На «@claude» нет ответа | Приложение Claude поставлено на этот репозиторий? Раздел **Actions** включён? Секрет добавлен и назван ровно так, как в таблице выше? |
| Ошибка проверки подлинности | Токен или ключ действителен? Имя секрета совпадает с именем в файле рабочего процесса? |
| Claude отвечает, но правок нет | Посмотрите его комментарий: возможно, он задаёт вопрос или сообщает, что задача непонятна |
| Проверки падают на правке Claude | Откройте `Проверки` в запросе на слияние, найдите упавший набор и напишите «@claude проверки падают, посмотри» в том же запросе |

Расход: каждый запуск тратит минуты GitHub Actions и, при работе по ключу API,
токены. Чем точнее задача, тем меньше уходит на неё обоих ресурсов.
