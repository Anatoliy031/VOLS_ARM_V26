Как это работает Инструменты считают величину и сразу сверяют её с нормативом по вашему объекту. Кнопка «Записать в измерения» переносит результат в осмотр — вручную ничего перепечатывать не нужно. Опор можно отметить сразу несколько: одно значение запишется отдельной строкой на каждую — удобно, когда результат одинаков для всей линии или для группы однотипных опор. Датчики телефона дают ориентировочную точность: для отчёта пользуйтесь поверенным прибором, а калькулятор берите для проверки и для пересчёта.

Если габарит считается, а не меряется

Габарит в середине пролёта = высота точки подвеса − стрела провеса. Стрела считается по приближению f ≈ q·L²/(8·H): q — погонная нагрузка, L — пролёт, H — тяжение. Это оценка для полевой проверки, точный расчёт — в проекте.
